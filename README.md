## ✨ Overview

AI Job Assistant is a full-stack AI application that helps users tailor their resumes to job descriptions using:
- Large Language Models (OpenAI)
- Skill gap analysis
- Resume scoring
- ATS-friendly formatting

---

## 🎯 Features

- 🔍 Skill Gap Analysis  
- 📊 Resume Scoring (0–100)  
- 🤖 AI Resume Optimization  
- 🖥️ Streamlit UI  
- 📄 PDF Export

## ⚙️ Setup

```bash
git clone https://github.com/your-username/ai-job-assistant.git
cd ai-job-assistant
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Create `.env`:

```
OPENAI_API_KEY=your_api_key_here
```

---

## ▶️ Run

```bash
streamlit run app/ui.py
```
